# The African Languages Lab — Interactive Research Demo

An interactive demo website for **“The African Languages Lab: A Collaborative
Approach to Advancing Low-Resource African NLP”** (Issaka et al., 2025,
arXiv:2510.05644), built for Jemimah Osei's portfolio. Jemimah is the 16th of
20 authors (Cornell University).

## What it is

A fully static site (HTML + CSS + vanilla JS, no build step, no backend) that
presents the paper interactively:

- **The problem** — 88% of African languages severely underrepresented or
  completely ignored; the 20–70× representation gap (paper Table 1).
- **What the lab did** — the All Voices platform, the dataset, fine-tuning.
- **Dataset explorer** — all 40 languages with tokens and audio hours
  (paper Table 2), sortable and filterable.
- **Model vs baseline** — the full Table 3: all 31 evaluated languages across
  ChrF++, COMET, BLEU, AfriCOMET, METEOR and TER, with a metric switcher
  and "beats Google Translate" highlights. Average gains: **+23.69 ChrF++,
  +0.33 COMET, +15.34 BLEU**.
- **Try it** — (A) a toy word-by-word English→Swahili baseline that runs in
  the browser, clearly labelled as a toy; (B) real fine-tuned-model output:
  the abstract's opening sentence in 6 languages, transcribed from the
  paper's Appendix B; (C) a clearly marked slot where Jemimah's live model
  plugs in next.
- **People, limits & ethics, sources** — full author list, the paper's own
  limitations, and the citation.

## Facts — where they come from

Every number on the site comes from the paper itself (abstract, Tables 1–3,
§6.2, Appendix B). Nothing is invented. The data file (`data.js`) was
generated by parsing the paper's own tables from the arXiv HTML version, so
the values match Table 2 and Table 3 exactly. Two paper quirks are preserved
and footnoted on the site: the paper prints "Afrkaans" in Table 3 (corrected
to Afrikaans) and Tshiluba's baseline BLEU as 5.856.

Note: a "dataset is 10,000+" figure appears in Jemimah's own notes about the
lab, but it does not correspond to a headline number in this paper (the
paper's headline is 19 billion tokens / 12,628 hours; 10,000 is the number of
translation pairs sampled per language pair in the validation pipeline,
§3.1). The site therefore leads with the paper's numbers and does not present
10,000+ as a dataset size.

## Run locally

```bash
cd african-nlp-tool
python3 -m http.server 8000
# open http://localhost:8000
```

No dependencies, no build step.

## How the live model plugs in later

`demo.js` has a `MODEL_API_URL` constant (currently `null`). When the
fine-tuned model has an HTTP endpoint, set it and wire the "C · Jem's model
plugs in here" panel to:

```
POST {MODEL_API_URL}/translate
{ "text": "…", "target_lang": "sw" }        # ISO 639-1 code, e.g. sw, ha, ig, yo, am
→ { "translation": "…", "model": "all-lab-llama-3.2-1b-ft", "source_lang": "en" }
```

Until `MODEL_API_URL` is set, the panel stays in its honest "not yet"
state and never fakes output.
