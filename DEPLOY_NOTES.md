## Paper facts used (all from Issaka et al. 2025, arXiv:2510.05644)

- Title/authors: 20 authors incl. Jemimah Osei (Cornell, 16th); submitted 7 Oct 2025; cs.CL.
- The gap: ~7,000 languages globally, <20 get serious NLP attention; 2,000+ African languages (~1/3 of world); 88% severely underrepresented or completely ignored; ~814 endangered; 20–70× representation gap (GS 20×, CORE 23×, arXiv 34×, IEEE 70×) — Table 1.
- Dataset: 19,012,019,696 tokens, 12,628 hours aligned speech, 40 languages (Table 2). Tiers: Amharic 2.94B, Arabic 2.40B, Yoruba 2.36B, Afrikaans 2.30B top; Fang 0.02M bottom; 147,000× disparity; 13 languages lack audio (§6.2).
- Method: Llama-3.2-1B base (never trained on these languages), full fine-tuning, instruction "Translate the following English text to X:", H100s, 1 epoch, FLORES-200 test set, 31 languages evaluated (9 excluded).
- Results (Table 3 averages): ChrF++ 8.10 → 31.79 (+23.69), COMET 0.32 → 0.65 (+0.33), BLEU 2.27 → 17.61 (+15.34); GT ChrF++ mean 44.14. TER average reduction 580.13 points; Swahili TER 23.77 = Google Translate.
- Highlights: Swahili ChrF++ +63.27 (9.00 → 72.27, vs GT 75.81); fine-tuned beats GT on ChrF++ in Twi (46.80 vs 31.48), Yoruba (30.88 vs 21.05), Arabic (31.52 vs 28.46), Sesotho (61.79 vs 57.01), Luganda (24.91 vs 23.55), Tigrinya (24.12 vs 23.75); Fon fell slightly (−1.10 ChrF++).
- Mentorship: 15 early-career researchers across 4 institutions. All Voices: mobile-first, direct LRL-to-LRL translation, peer validation (>5 upvotes, <3 downvotes), React Native + Firebase.
- Appendix B: abstract translated into 10 African languages by the fine-tuned models (Afrikaans, Amharic, Shona, Xhosa, Swahili, Malagasy, Igbo, Hausa, Arabic, Somali). The site shows the opening sentence in 6 of them, transcribed from the paper's PDF text layer (Somali lightly normalised where the text layer dropped characters; Arabic reconstructed in proper RTL order).
- Paper quirks preserved: Table 3 prints "Afrkaans" (corrected to Afrikaans on site, footnoted) and Tshiluba baseline BLEU as 5.856 (shown as printed, footnoted).
- The ADSABS abstract page could not be fetched during the build (fetch failed); the ADSABS link on the site is the URL jem supplied and is included as a link only, not as a source of facts.

## Deploy steps (for the parent)

1. Create a new GitHub repo (the GitHub App cannot create repos — create it in
   the browser while signed in as Jemimah, or have her create it).
2. Push this directory's contents to the repo root via the snapshot-push flow
   (text-only files; no binaries in this project).
3. In Render: New → Static Site from the repo, or sync the Blueprint
   (`render.yaml` defines service `african-nlp-tool`, env static,
   publish path `.`). No environment variables needed.
4. Verify live: homepage loads, dataset table shows 40 rows, results table
   shows 31 rows, metric switcher changes values, demo box translates the
   sample sentence, Appendix B tabs switch languages.
